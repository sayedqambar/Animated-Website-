1. GSAP (GreenSock Animation Platform)

GSAP is a JavaScript animation library.

It is used to create smooth, professional animations on websites.

For example:

Text animations
Buttons
Cards
Images
Scroll animations
Loading screens
Page transitions

Instead of writing lots of CSS animations, GSAP lets you animate elements with JavaScript.

Example

HTML:

<div class="box"></div>

CSS:

.box {
  width: 100px;
  height: 100px;
  background: red;
}

JavaScript with GSAP:

gsap.to(".box", {
  x: 300,
  duration: 2
});

The box moves 300px to the right over 2 seconds.

Another example:

gsap.from("h1", {
  y: -100,
  opacity: 0,
  duration: 1
});

The heading appears by sliding down from the top.

Where is GSAP used?
Portfolio websites
Agency websites
Landing pages
Product showcases
Interactive web experiences

Companies often use it to create polished animations.

2. WebSocket

A WebSocket is a communication protocol that creates a continuous, two-way connection between a client (browser) and a server.

Unlike normal HTTP requests, the connection stays open so both sides can send data whenever they need.

Normal HTTP
Browser ----Request----> Server

Browser <---Response----- Server

The connection ends after the response.

WebSocket
Browser <=================> Server
          Always Connected

Either side can send messages at any time.

Why use WebSocket?

Suppose you're using WhatsApp.

If your friend sends:

"Hello"

You don't want to refresh the page every second to see it.

Instead:

Friend
    │
    ▼
Server
    │
    ▼
Your browser

The message appears instantly because the server pushes it over the open WebSocket connection.

Where is WebSocket used?
Chat apps (WhatsApp, Discord)
Live notifications
Multiplayer games
Live stock prices
Cricket or football live scores
Real-time dashboards
Spring Boot Example

Spring Boot supports WebSocket.

Imagine a chat app:

React
     │
     ▼
Spring Boot WebSocket
     │
     ▼
Another React User

When User A sends a message:

Hello!

Spring Boot immediately forwards it to User B without requiring a page refresh.

REST API vs WebSocket
REST API	WebSocket
Request → Response	Continuous connection
Good for CRUD	Good for live updates
Used for login, products, users	Used for chat, notifications, live data
Stateless	Persistent connection
